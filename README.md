# Donut Chest Highlight

A client-side Minecraft Forge mod project for Minecraft Java 1.21.11.

The planned feature is to outline nearby chests (including copper and ender chests) and barrels. It is intended to be a visual convenience only; it does not reveal arbitrary player-placed blocks or hidden locations.

## Build

GitHub Actions attempts a build whenever code is pushed. Open the repository's **Actions** tab, choose **Build mod**, and download the `DonutChestHighlight-jar` artifact from a successful run.

Minecraft Forge 1.21.11 and Java 21 are required.
